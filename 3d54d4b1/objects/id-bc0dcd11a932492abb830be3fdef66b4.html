HOW TO READ THIS DIAGRAM This diagram provides a high-level overview of the technical architecture supporting the ViDA (VAT in the Digital Age) interoperable digital solution. At the top is the ViDA Interoperable Digital Solution, which can be accessed through two interfaces: a Machine-to-Machine Interface for automated system communication and a Human Interface for user interaction. Located at the centre of the diagram, the ViDA Digital Solution coordinates the ecosystem’s core functions across three domains: 1. eInvoice Data Transmission, supporting invoice data exchange; 2. eInvoice Data Governance, supporting control and management processes; 3. eInvoice Data Verification, supporting validation and verification activities. The Central VIES Shared Platform supports the ViDA Digital Solution and includes shared capabilities for APIs, messaging, VAT fraud management, and other infrastructure services like observability and monitoring.
