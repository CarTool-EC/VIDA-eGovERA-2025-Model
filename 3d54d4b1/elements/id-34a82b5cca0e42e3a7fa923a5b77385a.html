Secure Access to VIES data Value Stream ()
Description: This [Value stream] grouping contains all relevant elements of a specific value stream. A value stream represents a sequence of activities of the [Focal Public Administration] that create an overall [Public Value] for a [Stakeholder], by positively influencing a specific [Outcome] that realises a [Strategic goal] of the [Focal Public Administration. This value stream grouping contains a number of value stream subgroups that have the expected standard relations according to the PAAF RA. This allows architects to add elements to these subgroups without having to bother about the relations. For example, by adding the appropriate [Stakeholder] elements to the [Stakeholders] subgroup for a given value stream, the relation with the value created for those stakeholders and the further connection to the outcomes is documented in the relations between the subgroups.
