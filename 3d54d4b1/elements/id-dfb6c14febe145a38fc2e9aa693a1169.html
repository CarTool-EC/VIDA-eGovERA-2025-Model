European Interoperability Framework ()
Source: The New EIF. https://ec.europa.eu/isa2/eif_en The new European Interoperability Framework (EIF) is part of the Communication (COM(2017)134) from the European Commission adopted on 23 March 2017. The framework gives specific guidance on how to set up interoperable digital public services. This is an important policy document for implementing any European Interoperable Digital Public Service, and therefore an important driver for all EU Public Administrations.
