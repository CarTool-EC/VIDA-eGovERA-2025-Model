National Tax Administraton of «Member State» ()
Description: The National Tax Authority of a EU Member State is the Focal Public Administration of this enterprise architecture model. The PAAF Focal Public Administration ABB refers to the Public Administration that is modelled in this Enterprise Architecture model. All other ABB in this model have to be interpreted in the context of the Focal Public Administration, that is the central unit of analysis. Note: If the Focal Public Administration is part of a larger Public Administration, this can be indicated by including a Public Administration ABB with a composition or aggregation relationship. Occasionally, the Enterprise Architecture will document more than one Public Administration. In this case, this should also be reflected by including more than one Public Administration ABB in this group. Description: Add the name or title of the Focal Public Administration to the Name property of this ABB. Add a link to a web page describing the Focal Public Administration if possible, or add a small description in this "Documentation" part. Note: This ABB is inspired upon the EIRA "Public Administration" ABB.
