10.30 Assessments detail view ()
This view is included in the KU Leuven Public Administation Framework Reference Architecture to allow to document detailed strategic [Assessments] for the [Focal Public Administration]. Description: The process of defining Strategic goals for a Public Administration includes making Assessments. An Assessment represents the result of an analysis of the state of affairs of the Public Administration with respect to some Driver. What are the main strategic assessments of the] Focal Public Administration]? Are there any specific challenges the [Focal Public Administration] is facing? Document these assessments in this view, or provide links to the analysis documents. For example SWOT : Strengths, Weaknesses, Opportunities, Threats ? For example PESTEL : Political, Economic, Societal, Technological, Environmental or Legal factors influencing the strategy of the [Focal Public Administration] ? The "Public Management Reform Model (Pollitt & Bouckaert, 2017) can provide inspiration here and is included for this reason in this view.
